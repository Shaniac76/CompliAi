
# CompliAI MVP

This is a minimum viable product (MVP) for CompliAI, a compliance monitoring tool for AI usage within organizations.

## Features

- Simulated login (no backend or Firebase)
- Dashboard with dummy metrics and usage chart
- Tabs for Tool Usage, Reports, Alerts, and Settings
- Fully responsive layout using Tailwind CSS
- Lightweight, single-page HTML + JS

## How to Use

1. Open `index.html` in a web browser.
2. Click the login button to simulate login.
3. Navigate through the tabs to explore the features.

## Deployment

You can deploy this MVP using:
- GitHub Pages
- Netlify
- Vercel
- Or any static web host
